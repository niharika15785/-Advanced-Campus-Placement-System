# Advanced Campus Placement Management System

A Java and MySQL based application designed to manage campus placement activities.

## Features

- Student Registration and Login
- Company Registration and Login
- Job Posting
- Apply for Jobs
- Eligibility Checking
- Interview Scheduling
- Placement Result Management
- Search and Filters
- Dashboard

## Technologies Used

- Java
- MySQL
- JDBC
- Eclipse IDE

## Database

MySQL is used for storing student, company, job, application and placement-related data.

## Project Structure

- dao - Database access classes
- db - Database connection
- main - Main classes
- model - Model classes
- ui - User interface classes
